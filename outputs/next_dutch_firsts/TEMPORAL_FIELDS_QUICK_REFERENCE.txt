most_recent_record_year
  Value         Meaning
  ─────────────────────────────────────────────────────────────────────────

last_10yr_records (2016-2026 window)
  Value         Meaning
  ─────────────────────────────────────────────────────────────────────────
  6+            Established contemporary vagrant (multiple recent records)
  1-5           Rare contemporary vagrant (occasional recent records)

last_20yr_records (2006-2026 window)
  Value         Meaning
  ─────────────────────────────────────────────────────────────────────────
  6+            Regular vagrant with 20-year pattern
  1-5           Occasional vagrant over 20-year span
  0             Not recorded since before 2006 (very old records)
  (empty)       Unknown distribution - needs manual verification

EMPTY VALUES
─────────────────────────────────────────────────────────────────────────────
Empty fields appear when:
  • Records span across boundary year (e.g., records from 1990-2020)
  • No verified Dutch records exist
  • Source data too coarse for calculation

Empty ≠ Zero. Empty means "unknown" or "needs research"
Zero means "confirmed no records in that period"

FILTERING PATTERNS
─────────────────────────────────────────────────────────────────────────────

Get Currently Active Vagrants:
  most_recent_record_year >= 2020

Get Species Not Recorded Recently:
  most_recent_record_year < 2010

Get Established Contemporary Patterns:
  last_10yr_records > 0  (and not null)

Get Truly Unrecorded Species (Dutch First Candidates):
  most_recent_record_year IS NULL

Get Species Needing Manual Verification:
  last_10yr_records IS NULL  (but most_recent_record_year is not null)

MODEL FEATURES
─────────────────────────────────────────────────────────────────────────────

Recency Score: 2026 - most_recent_record_year
  • Lower = more recent
  • Can be used as regression feature
  • 0 for never recorded (outlier handling needed)

Activity Indicator: last_10yr_records > 0
  • Binary feature: 1 if active in past decade, 0 if not
  • Useful for vagrant vs. historical distinction

Trend: last_10yr_records - last_20yr_records
  • Positive = increasing activity
  • Negative = decreasing activity
  • Zero = stable pattern

WHEN TO USE EACH FIELD
─────────────────────────────────────────────────────────────────────────────

Use most_recent_record_year when:
  • Filtering for contemporary occurrences
  • Calculating recency-based features
  • Identifying most recently recorded species

Use last_10yr_records when:
  • Focusing on current decade patterns
  • Filtering out historical records
  • Assessing contemporary vagrant status

Use last_20yr_records when:
  • Examining mid-term trends
  • Identifying established patterns
  • Long-term trend analysis
