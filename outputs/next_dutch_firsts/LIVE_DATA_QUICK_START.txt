WHAT IS THIS?
─────────────
Next Dutch Firsts now integrates LIVE DATA from multiple sources to score
bird species by probability of Dutch occurrence. No more static CSVs!

QUICKEST START (Copy-Paste)
──────────────────────────

1. Run update:
   python scripts/update_live_data.py --cache

2. Score species:
   python scripts/update_live_data.py --score

3. Check results:
   head outputs/next_dutch_firsts/live_scores.csv

4. View status:
   python scripts/update_live_data.py


PYTHON API
──────────

# Update all sources
from src.next_dutch_firsts_live_data import create_live_data_manager
manager = create_live_data_manager()

import pandas as pd
df = pd.read_parquet("inputs/next_dutch_firsts/live/dutch_rarity_records.parquet")

HOW IT WORKS
────────────

1. UPDATE
   ┌──────────────────────────────────────────────┐
   │ External Data Sources                        │
   │ (Dutch Avifauna, eBird, Observation.org ...) │
   └──────────────┬───────────────────────────────┘
                  │
                  ↓
        [SourceAdapter Pipeline]
        fetch → validate → transform → load
                  │
                  ↓
   ┌──────────────────────────────────────────────┐
   │ Live Data Store (Parquet + CSV)              │
   │ inputs/next_dutch_firsts/live/               │
   └──────────────┬───────────────────────────────┘

2. SCORE
        ┌──────────────────────────────────────────┐
        │ LiveDataScorer                           │
        │ Priority: Live > Historical > Manual     │
        │ Tracks: Dutch records, recent activity, │
        │         Atlantic pathway, momentum      │
        └──────────────┬──────────────────────────┘
                       │
                       ↓
        Score (0-1) + Source Attribution

3. DISPLAY
        ┌──────────────────────────────────────────┐
        │ DataStatusDashboard                      │
        │ Text | HTML | Streamlit                  │
        │ Shows source health & update status      │
        └──────────────────────────────────────────┘


KEY CONCEPTS
────────────

QUALITY TIERS
  verified    → CDNA-accepted, institutional databases (0.9+ confidence)
  provisional → eBird unreviewed, community reports (0.7-0.8 confidence)
  unverified  → Social media, anecdotal (0.5-0.6 confidence)

SCORING LOGIC
  Dutch rarity: Not yet in Netherlands = highest score
  Recent activity: Recent European records boost score
  Momentum: Upward trend in records increases score
  Atlantic pipeline: Corvo/Ireland/UK presence indicates pathway

PRIORITY FALLBACK
  1. Live Data (e.g., from eBird today)
  2. Historical Data (e.g., species_master.csv)
  3. Manual Values (fallback to 0 or defaults)
  → Never blocks on missing sources; always returns a score


COMMON TASKS
────────────

Generate scores for all candidates:
  $ python scripts/update_live_data.py --score
  → Outputs: outputs/next_dutch_firsts/live_scores.csv

Schedule daily updates (Linux/macOS):
  $ crontab -e
  $ 0 3 * * * cd /path/to/repo && python scripts/update_live_data.py --cache

View live Dutch records:
  import pandas as pd
  df = pd.read_parquet("inputs/next_dutch_firsts/live/dutch_rarity_records.parquet")
  print(f"Dutch records: {len(df)}")

Filter by quality:
  verified = df[df['quality'] == 'verified']
  print(f"Verified records: {len(verified)}")

Score all species at once:
  from src.next_dutch_firsts_scoring import apply_live_scoring_to_candidates
  species = pd.read_csv("inputs/next_dutch_firsts/species_master.csv")
  scores = apply_live_scoring_to_candidates(species)
  scores.to_csv("outputs/live_scores.csv")


ADD A NEW DATA SOURCE
─────────────────────

1. Create adapter:
   class MyAdapter(SourceAdapter):
       def fetch(self): ...
       def validate(self, raw_data): ...
       def transform(self, raw_data): ...

2. Register:
   from src.next_dutch_firsts_live_data import create_live_data_manager
   manager = create_live_data_manager()
   manager.register_source(MyAdapter())

3. Update:
   manager.update_all_sources()

See LIVE_DATA_INTEGRATION_GUIDE.md for full examples.

TROUBLESHOOTING
───────────────

"No data loaded"
  → Check: ls -la inputs/next_dutch_firsts/live/
  → Verify source is registered: manager.list_sources()

"Source unavailable" warnings
  → This is normal; system continues with available data
  → To implement: add API key + implement fetch() method

"Old data in parquet"
  → Parquet accumulates records across updates
  → Reset: rm inputs/next_dutch_firsts/live/*.parquet
